# 日本向け原油輸送ルート：出典とコストの読み方

**確認基準日：2026年9月29日（日本時間）。同日中に最新公表資料で再検証・改訂。** 対象は原油で、LNG・LPG・石油製品の航路や運賃は含めない。航路は公開情報に基づく模式線であり、個船の航跡・定期運航・輸送量を表すものではない。公式の規則・事故情報、報道による観測・推計、作図上の判断を以下で区別する。基準日と各資料の観測・公表日は同一ではない。

## コスト表記の方法

バルーンは**輸送費の発生・増減要因を定性的に示す**。原油の購入価格・品質差・精製費を含む総調達費のランキングではない。日本着で積地、船型、貨物量、契約条件、評価日をそろえた公開運賃を確認できないため、同条件の見積額であるかのような比較は行わない。中型船や減載には積載効率の制約があるが、船腹市況・迂回距離・積替えの有無で費用は変わるため、一律に「単価増」とはしない。

相場の参考として9月29日に再確認した過去公表値は次のとおり。いずれも日本着の確約運賃や9月29日当日の価格ではなく、地図の定性的表示を補う参考値である。

| 公表日・出典 | 参考値 | 適用範囲・限界 |
|---|---|---|
| 9月17日・Kpler | ペルシャ湾→アジア：約30米ドル／バレル。オマーン湾→アジア：約20米ドル／バレル。 | 同社の原油VLCC市場分析。日本個別運賃ではない。差額を全便共通のホルムズ通過料金と解釈しない。 |
| 9月25日・Baltic Exchange | TD22 米国湾岸→中国：**5,250万米ドル超／航海**、27万トン原油。 | 中国向け指標。日本着やパナマ経由の費用へそのまま転用しない。 |

[Kpler、9月17日](https://www.kpler.com/blog/yanbu-pipeline-attack-ripples-across-crude-freight-and-gas-markets)／[Baltic Exchange、9月25日週報](https://www.balticexchange.com/en/data-services/WeeklyRoundup/tanker/news/2026/tanker-report-week-39.html)

Worldscale（WS）は航路別の基準運賃に対する指数なので、異なる航路のWS値を単純比較しない。TCEは船主の収益換算で、荷主の輸送費そのものではない。Affinityの「ソハール→日本 WS470」はLR2石油製品船の値であり、原油の費用から除外した。[Affinity、9月25日](https://www.affinityship.com/reports/affinity-tanker-weekly-25-september-2026)

## 主な航路・運用の根拠

- **紅海と北回り〔報道〕：** S&P Globalは9月17日時点で、9月9日以降のバブ・エル・マンデブにVLCC通航を確認せず、他船種は通航していると報告。北回り・喜望峰経由は**ヤンブーから紅海を南下する経路と比べて**少なくとも3週間長いとする。図にも比較対象を明記した。9月17日までの観測であり、9月29日の全船通航状況を断定するものではない。[S&P Global、9月17日](https://www.spglobal.com/energy/en/news-research/latest-news/shipping/091726-vlccs-avoid-red-sea-strait-as-houthi-threats-boosts-rates-amid-rising-shipping-risks)
- **日本向けSTS：** 日本の石油元売りがリンギ／タンジュン・ブルアスで積み替える運用を確認。6月の記事は経路の存在の根拠とし、9月の輸送量として扱わない。[S&P Global、6月9日](https://www.spglobal.com/energy/en/news-research/latest-news/shipping/060926-japan-refiners-deploy-vlccs-for-ship-transfers-us-crude-amid-hormuz-disruptions)
- **米国湾岸からの喜望峰航路〔報道〕：** 石油連盟会長への取材による約55日の説明と、VLCCのパナマ通航不可を確認。約55日は5月20日の説明であり、現在の所要日数の保証ではない。[Reuters／MarketScreener、5月20日](https://hk.marketscreener.com/news/japan-oil-refiners-expect-to-secure-enough-supply-to-replace-middle-east-crude-for-summer-ce7f5ad8d089f327)
- **パナマの船型と実績：** 日本向けSuezmaxの配船と減載予定が報じられた。運河庁の2026年規則では新閘門の最大幅は51.25 mで、幅約60 m級のVLCCは通れない。[Reuters、3月19日](https://www.marketscreener.com/news/us-crude-heads-to-asia-via-panama-canal-as-iran-crisis-redraws-trade-flows-ce7e5edede80f122)／[パナマ運河庁・2026年船舶要件](https://pancanal.com/wp-content/uploads/2021/08/N01-2026-Vessel-Requirements_BMV.pdf)
- **パナマの最新運用〔公式通知〕：** 運河庁の**A-36-2026（9月28日）**は、新閘門の最大許容喫水を**即時14.94 m**へ緩和し、**10月15日から33枠／日**へ増枠すると通知した。9月29日時点では32枠／日で、10月15日に新閘門が9→10枠、旧閘門が23枠となる。枠数は全船種合計で、原油船専用枠ではない。水不足は残り、予約未確保船の待機リスクも継続する。将来の運用条件はさらに変更されうる。[パナマ運河庁 A-36-2026、9月28日](https://pancanal.com/wp-content/uploads/2026/04/ADV-36-2026-Increase-in-the-Number-of-Neopanamax-Booking-Slots-Draft-Adjustment-and-Transit-Reservation-System.pdf)
- **パナマ旧告知の扱い〔改訂経緯〕：** 8月20日の告知にあった「10月1日から14.48 m」は、A-33-2026（9月4日）で延期済み。さらにA-36で14.94 mとなったため、旧数値を現況・確定予定として使用しない。これらは2026年の通知であり、過去年の渇水情報ではない。[当初の渇水対応告知、8月20日](https://pancanal.com/en/panama-canal-adopts-additional-measures-to-address-reduced-precipitation-in-the-canal-watershed/)／[A-33-2026、9月4日](https://pancanal.com/wp-content/uploads/2026/09/ADV-33-2026-Postponement-of-Maximum-Authorized-Draft-Adjustment-in-the-Neopanamax-Locks.pdf)
- **カナダから日本への直航：** Freedom Gloryは7月19日バンクーバー発、8月12日喜入着（24日）。約55.9万バレルという数量はS&Pの船舶追跡によるもので、ENEOS公表値ではない。[S&P Global、9月8日](https://www.spglobal.com/energy/en/news-research/latest-news/crude-oil/090826-appec-canada-expands-west-coast-crude-exports-to-meet-asian-demand)／[JETRO、8月13日](https://www.jetro.go.jp/biznews/2026/08/ce015bd0bc018974.html)
- **カナダの積出制約〔運営会社公表〕：** Westridgeの最大船型はAframaxで、港内喫水制限から通常約72.5万バレルの75～80%を積載する。直航の存在と積出能力・積載量の制約は両立する。将来のVLCC対応計画を現行設備として扱わない。[Trans Mountain、4月7日](https://www.transmountain.com/news/a-quiet-moment-on-the-dock-big-moment-for-the-team-500th-aframax)
- **カナダ直航の費用〔報道・作図判断〕：** Bloombergは9月25日、8月のバンクーバー→アジア輸送ではVLCCへの積替えがなかったと報じた。同記事は公表時点の比較として、Aframax直航の費用がVLCC積替経路の約54%とのArgus担当者のデータを紹介している。日本着同条件の見積もりではなく、この比率を全航路に適用しない。図は「直航で運河料・洋上積替費を回避」とし、従来の一律の「中型船・減載で単価増」を撤回した。[Bloomberg／Energy Connects、9月25日](https://www.energyconnects.com/news/oil/2026/september/canadian-oil-no-longer-takes-long-road-to-asia-as-freight-surges/)
