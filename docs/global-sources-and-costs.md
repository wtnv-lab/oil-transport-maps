# 日本向け原油輸送ルート：出典とコストの読み方

**確認基準日：2026年9月29日（日本時間）**。対象は原油で、LNG・LPG・石油製品の航路や運賃は含めない。航路は公開情報に基づく模式線であり、個船の航跡・定期運航・輸送量を表すものではない。

## 地図に反映した6系統

| 系統 | 現状と表現 | 主なコスト要因／リスク |
|---|---|---|
| 1. オマーン湾側→日本（湾内からのシャトルを含む） | フジャイラ・ソハールなど湾外の積出・積替拠点を利用。湾内からのシャトル船はホルムズを通過するため、海峡リスクが消えるわけではない。 | 船腹不足・保険・シャトル・積替え・滞船費。海峡や港湾周辺の攻撃、STS待ち。 |
| 2. ヤンブー→紅海南下→日本 | サウジ関連の大型原油船が回避する制約航路として破線表示。海峡全体の恒久的な全面閉鎖とはしない。 | 通航可能なら短いが、保険・運航条件が不安定。フーシ派による攻撃・拿捕の危険。 |
| 3. ヤンブー→SUMED／スエズ→地中海→喜望峰→日本 | 紅海南部を避ける北回り。SUMEDはアイン・スクナからシディ・ケリルへの陸上輸送と再積載を伴う。スエズ利用は船型・喫水条件に従う。 | 長距離迂回、荷役・再積載、燃料・傭船日数の増加。送油設備の復旧・再攻撃、接続遅延。 |
| 4. 米国メキシコ湾岸→喜望峰→日本 | VLCCによる大量輸送の経路。石油連盟会長は5月20日時点で約55日の航海と説明。所要日数は船速・港・待機で変わる。 | 長距離航海による燃料・傭船費と船腹拘束。荒天、納期長期化、船腹不足。 |
| 5. 米国メキシコ湾岸→パナマ→日本 | 中型船や減載したSuezmax等の経路。一般的なVLCCは幅の制約でも通航できず、減載だけでは解決しない。 | 運河料金と船型・積載量の制約。渇水による喫水・通航枠制限、予約待ち。 |
| 6. カナダ西岸→太平洋→日本 | 補完調達。バンクーバーから喜入への8月到着実績を反映し、主力供給と同じ規模とは扱わない。 | 運河料金は不要だが、積出港はAframax級・減載が基本。積出量・船型・油種適合の制約。 |

**ヤンブーの最新状況：** 9月28日のBloomberg配信は、東西パイプライン経由の輸出再開と約350万バレル／日（公称能力約700万バレル／日の半分）の通油を報じた。匿名関係者に基づき、Aramco・政府の確認発表ではないため、図では「輸出再開報道・復旧途上」とする。[Rigzone／Bloomberg、9月28日](https://www.rigzone.com/news/wire/saudi_arabias_key_oil_pipeline_starts_exports-28-sep-2026-184718-article/)

**STS（船から船への積替え）：** オマーン湾、西インド沖、マレーシアのリンギ沖を補完拠点として示す。全便がすべての拠点に立ち寄るわけではない。9月25日のReuters報道はフジャイラ・ソハールの能力制約と西インド・リンギへの分散を伝えている。[Reuters／EnergyNow、9月25日](https://energynow.com/2026/09/gulf-of-oman-ship-to-ship-oil-transfers-reach-limit-as-saudi-exports-surge/)

## コスト表記の方法

バルーンは**輸送費の増加要因を定性的に比較**する。原油の購入価格・品質差・精製費を含む総調達費のランキングではない。日本着で積地、船型、貨物量、契約条件、評価日をそろえた公開運賃を確認できないため、同条件の見積額であるかのような比較は行わない。

相場の参考として確認した数値は次のとおり。いずれも日本着の確約運賃や9月29日当日の価格ではなく、地図の定性的表示を補う参考値である。

| 公表日・出典 | 参考値 | 適用範囲・限界 |
|---|---|---|
| 9月17日・Kpler | ペルシャ湾→アジア：約30米ドル／バレル。オマーン湾→アジア：約20米ドル／バレル。 | 同社の原油VLCC市場分析。日本個別運賃ではない。差額を全便共通のホルムズ通過料金と解釈しない。 |
| 9月25日・Baltic Exchange | TD22 米国湾岸→中国：**5,250万米ドル超／航海**、27万トン原油。 | 中国向け指標。日本着やパナマ経由の費用へそのまま転用しない。 |

[Kpler、9月17日](https://www.kpler.com/blog/yanbu-pipeline-attack-ripples-across-crude-freight-and-gas-markets)／[Baltic Exchange、9月25日週報](https://www.balticexchange.com/en/data-services/WeeklyRoundup/tanker/news/2026/tanker-report-week-39.html)

Worldscale（WS）は航路別の基準運賃に対する指数なので、異なる航路のWS値を単純比較しない。TCEは船主の収益換算で、荷主の輸送費そのものではない。Affinityの「ソハール→日本 WS470」はLR2石油製品船の値であり、原油の費用から除外した。[Affinity、9月25日](https://www.affinityship.com/reports/affinity-tanker-weekly-25-september-2026)

## 主な航路・運用の根拠

- **紅海と北回り：** S&P Globalは9月17日時点で、9月9日以降のバブ・エル・マンデブにVLCC通航を確認せず、他船種は通航していると報告。北回り・喜望峰経由は南下より少なくとも3週間長いとする。9月17日までの観測であり、9月29日の全船通航を断定するものではない。[S&P Global、9月17日](https://www.spglobal.com/energy/en/news-research/latest-news/shipping/091726-vlccs-avoid-red-sea-strait-as-houthi-threats-boosts-rates-amid-rising-shipping-risks)
- **日本向けSTS：** 日本の石油元売りがリンギ／タンジュン・ブルアスで積み替える運用を確認。6月の記事は経路の存在の根拠とし、9月の輸送量として扱わない。[S&P Global、6月9日](https://www.spglobal.com/energy/en/news-research/latest-news/shipping/060926-japan-refiners-deploy-vlccs-for-ship-transfers-us-crude-amid-hormuz-disruptions)
- **米国湾岸からの喜望峰航路：** 石油連盟会長への取材による約55日の説明と、VLCCのパナマ通航不可を確認。[Reuters／MarketScreener、5月20日](https://ca.marketscreener.com/news/japan-oil-refiners-expect-to-secure-enough-supply-to-replace-middle-east-crude-for-summer-ce7f5ad8d089f327)
- **パナマの船型と実績：** 日本向けSuezmaxの配船と減載予定が報じられた。運河庁の2026年規則では新閘門の最大幅は51.25 mで、幅約60 m級のVLCCは通れない。[Reuters、3月19日](https://www.marketscreener.com/news/us-crude-heads-to-asia-via-panama-canal-as-iran-crisis-redraws-trade-flows-ce7e5edede80f122)／[パナマ運河庁・2026年船舶要件](https://pancanal.com/wp-content/uploads/2021/08/N01-2026-Vessel-Requirements_BMV.pdf)
- **パナマの9月制約：** 運河庁は9月15日から32枠／日、9月2日から最大喫水14.63 m、10月1日から14.48 mへの変更予定を公表。枠未確保の船は待機が長くなる可能性がある。[パナマ運河庁・渇水対応告知](https://pancanal.com/en/panama-canal-adopts-additional-measures-to-address-reduced-precipitation-in-the-canal-watershed/)
- **カナダから日本への直航：** Freedom Gloryは7月19日バンクーバー発、8月12日喜入着（24日）。約55.9万バレルという数量はS&Pの船舶追跡によるもので、ENEOS公表値ではない。[S&P Global、9月8日](https://www.spglobal.com/energy/en/news-research/latest-news/crude-oil/090826-appec-canada-expands-west-coast-crude-exports-to-meet-asian-demand)／[JETRO、8月13日](https://www.jetro.go.jp/biznews/2026/08/ce015bd0bc018974.html)
- **カナダの積出制約：** 運営会社によるとWestridgeの最大船型はAframaxで、喫水制限から通常約72.5万バレルの75～80%を積載する。[Trans Mountain、4月7日](https://www.transmountain.com/news/a-quiet-moment-on-the-dock-big-moment-for-the-team-500th-aframax)
