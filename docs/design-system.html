01文字の階層

地理は明朝、輸送は角ゴシック。
主要な地物だけに細い縁取りを付ける。

02線と地点記号

鮮やかな線を暗い背景に重ねる。
往復・送油方向・通航制約を形でも区別する。

03注記と引出線

見出し → 状況 → コスト → リスク。
線を文字に重ねず、対象の線上で止める。
